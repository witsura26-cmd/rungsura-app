เนื้อเพลง

แปะเนื้อเพลงพร้อมใส่ label นำแต่ละท่อน ใช้แบบนี้ (บรรทัดของตัวเองสำหรับ label):
[Verse 1] [Verse 2] ... = ท่อน verse
[Pre-Chorus] = ท่อนก่อน chorus
[Chorus] = ท่อนฮุก
[Bridge] = ท่อนเชื่อม
[Intro] [Outro] [Instrumental] = ท่อนดนตรี/เปิด-ปิด
ถ้าท่อนไหนเป็นการ "ร้องซ้ำ" ของท่อนก่อนหน้า ใส่ * ต่อท้าย label เช่น [Chorus] *

เปิดไฟล์ walnut-songs.js หา const SONGS = [ แล้ววาง object ด้านล่างนี้เป็นบรรทัดแรกถัดจากนั้น (อย่าลืม comma , ต่อท้าย ถ้ามีเพลงอื่นตามหลัง)
