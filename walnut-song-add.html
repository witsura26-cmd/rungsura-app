🎵 Walnut Song - เครื่องมือเพิ่มเพลง

แปะเนื้อเพลงพร้อม label แล้วกด "แปลงเป็น JSON" จะได้โค้ดพร้อมวางลงใน walnut-songs.js ทันที (ทำงานในเบราว์เซอร์ล้วนๆ ไม่ส่งข้อมูลไปไหน)

ข้อมูลเพลง

โหมด 1: วางเนื้อเพลงดิบ ให้ระบบเดาท่อนให้ (แนะนำ)

วางเนื้อเพลง ไม่ต้องใส่ label — แค่เว้นบรรทัดว่าง 1 บรรทัดคั่นระหว่างแต่ละท่อน (verse/chorus/bridge ฯลฯ) เหมือนที่เว็บเนื้อเพลงทั่วไปจัดมาให้อยู่แล้ว
ระบบจะเดาว่าท่อนไหนเป็น chorus โดยดูจากท่อนที่ข้อความซ้ำกันเป๊ะ (เพราะ chorus มักร้องซ้ำคำเดิม) ท่อนอื่นจะเดาเป็น verse ตามลำดับ — กดปุ่มด้านล่างแล้วเช็ค/แก้ dropdown ให้ถูกอีกทีได้ก่อนสร้าง JSON

โหมด 2: พิมพ์ label เอง (สำหรับกรณีระบบเดาผิด)

แปะเนื้อเพลงพร้อมใส่ label นำแต่ละท่อน — จะขึ้นบรรทัดใหม่ต่างหาก หรือพิมพ์ต่อท้ายในบรรทัดเดียวกันก็ได้ทั้งคู่ (เช่น [Verse 1] หรือ [Verse 1] เนื้อร้องบรรทัดแรก):
[Verse 1] [Verse 2] ... = ท่อน verse
[Pre-Chorus] = ท่อนก่อน chorus
[Chorus] = ท่อนฮุก
[Bridge] = ท่อนเชื่อม
[Intro] [Outro] [Instrumental] = ท่อนดนตรี/เปิด-ปิด
ถ้าท่อนไหนเป็นการ "ร้องซ้ำ" ของท่อนก่อนหน้า ใส่ * ต่อท้าย label เช่น [Chorus] *
หลังกดแปลง จะมีรายการท่อนขึ้นด้านล่างให้เช็คจำนวนบรรทัด ก่อน copy ไปวางในไฟล์

ผลลัพธ์ - copy แล้วไปวางใน walnut-songs.js

เปิดไฟล์ walnut-songs.js หา const SONGS = [ แล้ววาง object ด้านล่างนี้เป็นบรรทัดแรกถัดจากนั้น (อย่าลืม comma , ต่อท้าย ถ้ามีเพลงอื่นตามหลัง)
